### Vue commands
- ``` boil vue-ts-wind-vitest <my-project-name>``` (Vue + TypeScript + Tailwind + Vitest)
- ``` boil vue-js-wind-vitest <my-project-name>``` (Vue + JavaScript + Tailwind + Vitest)
- ``` boil vue-ts-wind <my-project-name>``` (Vue + TypeScript + Tailwind)
- ``` boil vue-js-wind <my-project-name>``` (Vue + JavaScript + Tailwind)
- ``` boil vue-ts-vitest <my-project-name>``` (Vue + TypeScript + Vitest)
- ``` boil vue-js-vitest <my-project-name>``` (Vue + JavaScript + Vitest)
- ``` boil vue-ts <my-project-name>``` (Vue + TypeScript)
- ``` boil vue-js <my-project-name>``` (Vue + JavaScript)
