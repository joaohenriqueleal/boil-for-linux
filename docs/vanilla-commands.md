### Vanilla commands
- ``` boil vanilla-ts-wind <my-project-name>``` (Vanilla + TypeScript + Tailwindcss)
- ``` boil vanilla-js-wind <my-project-name>``` (Vanilla + JavaScript + Tailwindcss)
- ``` boil vanilla-ts <my-project-name>``` (Vanilla + TypeScript)
- ``` boil vanilla-js <my-project-name>``` (Vanilla + JavaScript)
